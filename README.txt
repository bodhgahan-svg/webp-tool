Bulk WebP Optimizer Pro - Instructions

Thank you for your purchase!

Note: Since this is an independent desktop utility, Windows SmartScreen might show an 'Unknown Publisher' warning on first launch. 
Simply click "More info" and then "Run anyway" to start using the app.

How to use:
1. Double-click main.exe
2. Click "Select Folder & Convert"
3. Choose your image folder and your WebP images will be saved automatically!
